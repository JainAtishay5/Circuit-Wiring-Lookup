
# Circuit Wiring Lookup System

A Python-based circuit wiring lookup tool that generates and retrieves wiring information for 72 circuits.

## Features

- Supports circuits c1 to c72.
- Automatically generates wiring data.
- Groups circuits into blocks of six.
- Automatically assigns Power TB and RTD terminals.
- Displays wiring information in a tabular format.
- Exports wiring data to CSV.

## Technologies Used

- Python 3
- CSV Module
- Git
- GitHub

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run:

   python main.py

4. Enter a circuit number (e.g. c1, c25, c72).
5. Type exit to close the program.

## Project Structure

- main.py: Main Python application.
- circuit_wiring.csv: Automatically generated wiring database.
- README.md: Project documentation.
